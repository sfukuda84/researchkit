# researchkit-analysis: 詳細（methods.md）

[SKILL.md](../SKILL.md) の本文から移した詳細。本文の要点で足りないとき、ここを読む。見出しは本文と同じ番号を使う。

### 4.1 デスクリサーチ（`desk`）

- **主張と根拠の表**: 主張の候補ごとに、支持する根拠と反する根拠（出典 ID と抜き書きの番号）、根拠の等級、一次資料かを並べる。候補は Q10 で主張（`C1`〜）になる。
- **比較表**: 競合・技術・制度などを比べるときは、比べる観点を先に決め（`plan.md`）、セルごとに出典 ID を付ける。分からないセルは「不明（search-log.md #n で探した）」と書き、空けない。
- **推計**（フェルミ推定など）: 前提を表にし、前提ごとに値・出典（または「仮定」と理由）・幅（低・基準・高）を書く。計算はスクリプトにし、幅の組み合わせで結果の幅（感度）も出す。前提の 1 つが結果を大きく動かすなら、その前提を Q10 の限界に書く。

### 4.2 文献レビュー（`literature`）

- **抽出表**: 採用した研究ごとに、出典 ID、研究の設計、対象と標本の大きさ、介入・曝露と比較、結果の指標と値、資金の出所、質の評価を書く。抽出の項目は `plan.md` で決めたものを使う。
- **研究の質の評価**: 研究の設計に合う道具を使う。例: 無作為化比較試験は Cochrane の RoB 2、非無作為化の介入研究は ROBINS-I、観察研究は Newcastle–Ottawa Scale、質的研究は CASP のチェックリスト、系統的レビューは AMSTAR 2。どの道具を使うかは `plan.md` に従う。根拠の全体の確かさを段階で表すなら GRADE の考え方を参考にし、Q10 の確度に対応づける。
- **統合**: 効果の指標が揃い、研究が十分に似ているときだけ、簡易なメタ分析（変量効果モデルなど）をスクリプトで行い、異質性（I² など）も出す。そうでなければナラティブ統合にし、研究を結果の向き・設計・対象で分けて表にまとめる。票を数えるだけの統合（有意な研究の数で決める）はしない。
- **出版バイアス**: 灰色文献（報告書、学位論文、学会抄録）を探したか、否定的な結果の研究があるかを記録する。

### 4.4 定性調査（`qualitative`）

- **匿名化を先に行う。** 文字起こし・自由記述から、名前・所属・地名・日付など個人を特定できる情報を記号（`P01`、`[会社A]`）に置き換えてから分析する。匿名化の規則を `analysis.md` に書く。
- **コーディング表**: コードごとに、名前、定義、含めるもの・含めないもの、例（`P03` の発言と位置）、該当した対象者の数を書く。最初のコードは `plan.md` の問いから作り（演繹）、データから出たコードを足す（帰納）。足したコードは、いつ・なぜ足したかを書く。
- **テーマの抽出**: コードをまとめてテーマにする。方法は `plan.md` に従う（例: Braun と Clarke（2006）のテーマ分析、川喜田二郎の KJ 法）。テーマごとに、支える発言と、合わない発言（反例）を並べる。
- **数を数えるとき**: 「8 人中 5 人」のような数は、コーディング表から数える（スクリプトか `{N:calc}`）。少数の対象者の数を、母集団の割合のように書かない。
- 可能なら、2 人目（`[人]`）が一部をコーディングして、コードの当て方を照合する。できないときは、その旨を限界に書く。
