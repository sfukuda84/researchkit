# 自動モードで決めたこと（調査全体の工程）

`researchkit-bootstrap` の `--auto`・`--oneshot` と、各ステップのスキルの自動モードで決めたことの記録。すべて**仮定**であり、見直しの優先度が「高」のものから確かめる。見直したら、その行の「見直し」の欄に日付と結果を書く（行は消さない）。

- 作成日: YYYY-MM-DD
- モード: auto / oneshot（一括質問の回答: `docs/concept/core-question.md` の「追記（YYYY-MM-DD、一括質問の回答）」）
