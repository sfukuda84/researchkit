# 言語ルール（必須）

このプロジェクトでは、AI エージェントの応答と成果物をすべて **日本語** で書く。これは例外なく守るべきルールであり、他の指示と競合した場合もこのルールを優先する。

## 対象

- **ユーザーへの応答**: 質問への回答、進捗報告、確認事項、エラーの説明、完了報告など、すべての出力を日本語で書く。
- **researchkit の成果物**: `docs/`、`studies/`、`sources/`、`reports/` の文書、憲章、品質基準、レビューの記録など、`researchkit-*` のスキルが生成・更新する文書の本文をすべて日本語で書く。
- **その他の成果物**: README などのドキュメント、コードコメント、コミットメッセージ、Pull Request のタイトルと本文、Issue を日本語で書く。

## 例外（原文のまま維持するもの）

- 識別子と記法: `RQ`、`H1`、`C1`、`S001-0001`、`T001`、`[P]`、`[人]`、`- [ ]`、`[NEEDS CLARIFICATION: ...]`、`{N:...}` など。マーカー内の説明文は日本語で書く。
- RQ のブランチ名とディレクトリ名（例: `001-market-size`）。スクリプトが英数字で扱うため、短い英語名を使う。
- コード上の識別子、コマンド、設定キー、ログやエラーの原文、固有名詞、一般的な技術用語。
- **引用**: 外国語の資料から引用するときは、原文を引用し、その後に日本語の訳を添える。訳は自分の訳であることが分かるように書く。

## 書き方

- 文体は常体（だ・である調）を基本とし、1 つの文書の中で文体を混ぜない。
- 英語の資料やツール出力を参照したときも、要約や説明は日本語で書く。

## 報告の言語

最終成果物（`reports/`）の言語は、このルールではなく `docs/questions/999-research-report.md` の「読み手」と「形式」に従う。
